FastFrame Demo Setup Guide

Google Drive API Setup

Follow this step-by-step guide to create a Google Cloud project, enable the Google Drive API, create a service account, and generate the JSON credentials required for your application.

Step 1 Step 2 Step 3

Setup Instructions

Complete each step in order. The entire process only requires a Google Cloud project and a Google account.

1

Create a Google Cloud Project & Enable the API

Create the project that will contain your Google Drive API configuration.

  1. Log in to the Google Cloud Console using your new testing email.
  2. Accept the Google Cloud Terms of Service if prompted.
  3. In the top-left project dropdown, next to the Google Cloud logo, click New Project.
  4. Enter a project name such as FastFrame Demo and click Create.
  5. Once the project is created, make sure the new project is selected in the top project dropdown.
  6. Open the left sidebar and go to: APIs & Services → Library.
  7. Search for Google Drive API.
  8. Open the Google Drive API page and click the blue Enable button.
Open Google Cloud Console ↗
2

Create the Service Account

Create the service account that will act as the application's bot.

  1. In Google Cloud Console, open the left sidebar and navigate to: APIs & Services → Credentials.
  2. Click the + CREATE CREDENTIALS button at the top.
  3. Select Service Account.
  4. Under Service account details, enter a name such as studio-bot.
  5. Click Create and Continue.
  6. Under Grant this service account access, you can skip this step and click Continue.
  7. Under Grant users access, skip this step and click Done.
3

Generate and Download the JSON Key

Create a private JSON key for the service account.

  1. You will now see your newly created service account listed under Service Accounts.
  2. The service account will have an email address similar to:

    studio-bot@fastframe-demo-123.iam.gserviceaccount.com
  3. Click the pencil/edit icon next to the service account, or click the service account email address.
  4. Open the Keys tab.
  5. Click Add Key → Create new key.
  6. Select JSON as the key type.
  7. Click Create.
  8. A file named credentials.json will be downloaded to your computer.
⚠️ Important:
The credentials.json file contains a private service-account key. Do not upload it to GitHub, publish it publicly, or share it with unauthorized people.
✓

Setup Complete

Once you have successfully downloaded credentials.json, the Google Cloud service account setup is complete. You can now use the credentials with your application to authenticate with Google Drive.
